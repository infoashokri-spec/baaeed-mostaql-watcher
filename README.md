# مراقب بعيد ومستقل

مراقب عام يعمل عبر GitHub Actions ويرسل الروابط الجديدة إلى بوت Telegram. لا يحتوي المستودع على بيانات عملاء أو ملفات مشاريع، وتبقى بيانات البوت داخل GitHub Secrets المشفرة.

## المصادر النشطة

- مستقل: المشاريع الجديدة.
- بعيد: الوظائف عن بعد.

## طريقة العمل

- يبدأ GitHub Actions الفحص كل خمس دقائق تقريبًا.
- أول تشغيل يحفظ الروابط الحالية كخط أساس، ولا يرسلها كأنها جديدة.
- في التشغيلات التالية تُرسل الروابط التي لم تظهر من قبل فقط.
- تحفظ الحالة في `data/state.json`، ولا يحدث المستودع إلا عند ظهور رابط جديد أو تغير
  حالة خطأ.
- بعد ثلاثة إخفاقات متتالية لمصدر واحد، يرسل البوت تنبيهًا واحدًا ولا يكرره حتى
  يتعافى المصدر.

## أسرار المستودع المطلوبة

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

لا تضع رمز البوت أو أي بيانات دخول داخل الملفات العامة.
